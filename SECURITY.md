# Security policy

Reporte vulnerabilidades de forma privada aos mantenedores, sem incluir dados reais de alvos. Não abra issues públicas com scopes, inventários ou relatórios de laboratório.

O projeto aceita somente análise passiva de arquivos locais. Propostas de exploração, execução remota, payloads, persistência, evasão, brute force ou coleta de credenciais estão fora de escopo.
